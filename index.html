About

I started writing code in 2021, in a browser tab and a text editor, because I wanted a website that did something. The website turned into a habit.

Most of what I build starts as a small annoyance I want to be rid of. A Drive link that won't download directly becomes Downract. A browser with no ad blocker worth the name becomes SBrows. A chatbot that answers every question with confident nonsense becomes TarkikX, which only tells you what it actually found.

These days it's desktop tooling in Python, small web apps, and 3D game development in Godot. I care about things that ship and keep working: one file that does its job beats a framework that needs a build step to say hello. I'm self-taught, I read source code for fun, and I'd rather show you nineteen repositories than describe my skills as a percentage.

Selected work

Four projects that show how I think.

2026 ↗

SBrows

A browser, from scratch

A working desktop browser in a single ~1,100-line Python file: movable tabs with favicons, private tabs on an off-the-record profile, a built-in ad blocker, bookmarks, downloads, find-in-page, PDF export and session restore — with no external icon assets.

  • Python
  • PyQt6
  • QtWebEngine
2026 ↗

PSSC

A cipher I designed myself

A symmetric stream cipher in pure Python, no crypto libraries. Version 2 is a pseudo one-time pad: each character is shifted by an independent random key digit across an 82-character alphabet, which kills the frequency analysis that breaks static substitution ciphers. Includes serialisation and payload obfuscation.

  • Python
  • Cryptography
  • Algorithms
2026 ↗

TarkikX

Answers without a language model

A chatbot that retrieves and summarises from DuckDuckGo and Wikipedia instead of generating text, so every answer traces back to a page that exists. Session history, dark and light UI, and no third-party AI behind it.

  • Python
  • JavaScript
  • Retrieval
2022 ↗

PyExe-GUI

Python to .exe, without the terminal

A desktop tool that turns a Python file into a Windows .exe through a window instead of a command you have to remember. Built with Apoorv Mittal and Sujal Choudhari as a single .pyw file, MIT licensed — and the first project where I was designing for someone who wasn't me.

  • Python
  • Desktop
  • MIT

Also on GitHub: reelScroll, trackmail, SU, TTS-GUI, androidQuiz ↗
